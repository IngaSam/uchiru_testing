# Тест-кейсы. Тестирование главной страницы Учи.ру

---

## Тест-кейс №1: Проверка названия платформы

| Поле | Значение |
|------|----------|
| **ID** | TC-01 |
| **Название** | Проверка корректности написания бренда «Учи.ру» в шапке сайта |
| **Приоритет** | Medium |
| **Тип** | Позитивный |
| **Предусловие** | Открыта главная страница сайта |

**Шаги воспроизведения:**
1. Найти фиолетовую область в верхней части страницы (шапку)
2. Найти текст, содержащий название платформы
3. Сверить написание с эталоном «Учи.ру»

**Ожидаемый результат:**  
Название платформы написано как «Учи.ру». Ошибки типа «Учи.у», «Учи.р» или другие опечатки отсутствуют.

**Постусловие:** не требуется

## Тест-кейс №2: Проверка карточек курсов

| Поле | Значение |
|------|----------|
| **ID** | TC-02 |
| **Название** | Проверка наличия описания у всех карточек в блоке подготовки к экзаменам |
| **Приоритет** | Medium |
| **Тип** | Позитивный |
| **Предусловие** | Открыта главная страница, страница прокручена до блока «А ещё подготовка к ВПР, ОГЭ и ЕГЭ и другие развивающие занятия» |

**Шаги воспроизведения:**
1. Найти карточку «Программирование» → проверить наличие поясняющего текста
2. Найти карточку «Планирование» → проверить наличие поясняющего текста
3. Найти карточку «Магическая математика» → проверить наличие поясняющего текста
4. Найти карточку «Чтение» → проверить наличие поясняющего текста

**Ожидаемый результат:**  
У каждой из четырёх карточек есть поясняющий текст под заголовком. Ни одна карточка не осталась без описания.

**Постусловие:** не требуется

## Тест-кейс №3: Проверка списка предметов

| Поле | Значение |
|------|----------|
| **ID** | TC-03 |
| **Название** | Проверка отсутствия технических заглушек в списке предметов |
| **Приоритет** | High |
| **Тип** | Позитивный |
| **Предусловие** | Открыта главная страница, выбран режим «Ученикам» |

**Шаги воспроизведения:**
1. Прокрутить страницу до блока «Интерактивные курсы для 1–11 классов»
2. Визуально проверить каждый пункт списка предметов

**Ожидаемый результат:**  
Все пункты списка — реальные названия школьных предметов. Отсутствуют элементы вида «subject», «undefined» и другие технические заглушки.

**Постусловие:** не требуется

## Тест-кейс №4: Проверка валидации пустых полей

| Поле | Значение |
|------|----------|
| **ID** | TC-04 |
| **Название** | Проверка валидации формы входа при пустых полях |
| **Приоритет** | High |
| **Тип** | Негативный |
| **Предусловие** | Страница авторизации загружена |

**Шаги воспроизведения:**
1. Оставить поле «Логин» пустым
2. Оставить поле «Пароль» пустым
3. Нажать кнопку «Войти»

**Ожидаемый результат:**  
Появляется сообщение об ошибке (например, «Заполните логин и пароль») или поля подсвечиваются красным. Вход не выполняется.

**Постусловие:** не требуется
