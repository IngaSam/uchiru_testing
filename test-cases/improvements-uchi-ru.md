## Пример оформления одного предложения (развёрнуто)

### Улучшение №1: Добавить кнопку «глазик» для показа пароля

**Текущая ситуация:**  
Поле пароля скрывает символы точками. Пользователь не может проверить, правильно ли он ввёл пароль.

**Проблема:**  
Частые ошибки при вводе → повторные попытки → раздражение пользователя.

**Решение:**  
Добавить иконку (глаз) внутри поля пароля. При нажатии символы временно отображаются открыто.

**Ожидаемый результат:**  
- Снижение количества ошибок ввода пароля
- Улучшение пользовательского опыта (UX)

**Пример реализации:**  
[как на большинстве современных сайтов — иконка справа внутри поля]
